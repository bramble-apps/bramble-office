# Logic Pro 13 Settings window, transcribed tab by tab for Bramble Studio (dark appearance).
# Source: research screenshots (about 2x) + accessibility dumps. Order/rows/labels from the PNGs; strings/values from the dumps.
# Format: row<TAB>left label<TAB>kind<TAB>text<TAB>default<TAB>choices
#   kinds: check, popup, stepper, slider, radio, button, text, field, group <title>/endgroup, separator, table
#   left label "^" = this control sits on the SAME line as the row above, to its right (sliders' steppers, units, second grid column).
#   "# heading" before a text row = bold 13pt section heading, flush left at the content edge (not a label column item).
#   "# small" before a text row = 11pt help/info text.
#   choices starting with "~" were not seen in the research (standard Logic knowledge).
#   "(disabled)" after a control's text = drawn greyed out.
# Tabs with sub-tabs draw all their rows inside the sub-tab group box (segmented control centred on its top border);
#   that outer box is described under "look" and is not repeated as group/endgroup. Rows marked "below the box" sit outside it.
# Privacy: device names replaced with "System Default". Sound Library sub-tab left out (shows a path). My Info tab not researched.
#
# look: all sizes in points (PNG px / 2), colours sampled from the PNGs (dark mode).
# look: window width 750 (height per tab below); outer corner radius large (~10+), 0.5pt black outline.
# look: title band (title bar + icon tab row) fill #2e2d2c, 88 tall incl. title bar; 0.5pt divider #353433 at its bottom; body below #262524.
# look: title "Settings" bold 13pt, #aaa9a8, centred, cap top y≈10.5. Traffic lights ~14 dia at x 9..22.5, y 10..21.5 (red #e1675b, others #525150).
