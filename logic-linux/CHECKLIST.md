# Bramble Studio — 1-1 checklist and self-audit

The goal is Logic Pro 13, 1-1 in every way: the same windows, menus, right-click menus, key
commands, drags and gestures, animations, editors, instruments, effects and Session Players. It
also opens and saves real `.logicx` and GarageBand `.band` projects. Built from scratch on the
suite's shared code (kn-ui: window frame, pointer fixes, themes, liquid glass, Sfera fonts).

Status: `[x]` done and checked, `[~]` partly there (the note says what's missing), `[ ]` not started.
The item-by-item lists at the bottom (menus, right-click menus, key commands) are generated by
`tool/checklist.py`; re-run it after each change. The audit below is written by hand.

## Honest audit (2026-11-10)

The first draft opened and played real projects, but most of Logic was missing: about 6% of
the menu bar, 2% of the key commands, no right-click menus, one effect, and a General MIDI
SoundFont in place of every instrument. The drummer was a stub. Everything below is the way to 1-1.
