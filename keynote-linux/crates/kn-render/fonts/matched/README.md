# Matched fonts

Free fonts made metric-compatible with Apple fonts: the same advance widths, kerning and
line metrics, so a Pages / Keynote / Numbers document lays out line for line as on a Mac
where the Apple font isn't installed. Each font names the Apple font it is compatible with
in name record 32000, which kn-render reads (`Fonts::choose`). Made with
~/CascadeProjects/matched-fonts (its README has the method and each family's limits);
regenerated by its `tools/export_to_suite.py`.

The names only start like the originals: "SF Pro", "Helvetica", "Futura" … are
trademarks of their owners, who have nothing to do with these fonts.
